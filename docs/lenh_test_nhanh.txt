DANH SÁCH LỆNH TEST NHANH - P2P WALLET (Windows PowerShell)
Môn: Kiến trúc Hướng Dịch Vụ - Người 2 (ERD, Backend thuần, Trang admin)

Yêu cầu: Python 3.8+, mở PowerShell tại thư mục gốc của dự án (p2p-wallet).
Dùng 2 cửa sổ PowerShell: Terminal 1 chạy server, Terminal 2 chạy các lệnh test.


==================================================
BƯỚC 1 - KHỞI ĐỘNG (Terminal 1)
==================================================

python database/init_db.py
python backend/server.py

Kết quả mong đợi: "Server dang chay tai http://127.0.0.1:8000"
Dừng server: Ctrl+C


==================================================
BƯỚC 2 - XEM TRANG ADMIN (trình duyệt)
==================================================

http://127.0.0.1:8000/admin

Hiển thị 4 bảng đọc từ DB thật: Users, Wallets, Transactions, Ledger.
Bấm "Tai lai du lieu" để cập nhật sau mỗi thao tác.


==================================================
BƯỚC 3 - ĐỌC DỮ LIỆU QUA API (Terminal 2)
==================================================

Invoke-RestMethod http://127.0.0.1:8000/api/users
Invoke-RestMethod http://127.0.0.1:8000/api/users/2
Invoke-RestMethod http://127.0.0.1:8000/api/wallets
Invoke-RestMethod http://127.0.0.1:8000/api/transactions
Invoke-RestMethod http://127.0.0.1:8000/api/ledger


==================================================
BƯỚC 4 - LỖI ROUTING: 404 VÀ 405
==================================================

curl.exe -i http://127.0.0.1:8000/api/users/999
curl.exe -i http://127.0.0.1:8000/api/transfers

Mong đợi: lệnh 1 trả 404 (không tìm thấy user),
lệnh 2 trả 405 (đường dẫn có nhưng sai method, route này chỉ nhận POST).


==================================================
BƯỚC 5 - LUỒNG CHUYỂN TIỀN CÓ OTP
==================================================

5.1 Tạo giao dịch: ví 1 chuyển ví 2, 50.000 VND

$body = @{sender_wallet_id=1; receiver_wallet_id=2; amount=50000} | ConvertTo-Json
$r = Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/api/transfers -ContentType "application/json" -Body $body
$r

Mong đợi: status PENDING, có transaction_id và demo_otp.
Terminal 1 in dòng [EMAIL -> vi 1] OTP giao dich ...
Lúc này số dư chưa đổi:

Invoke-RestMethod http://127.0.0.1:8000/api/wallets

5.2 Chuẩn bị file JSON cho các lệnh curl (bắt buộc -Encoding ascii)

Set-Content -Path wrong.json -Value '{"code":"000000"}' -Encoding ascii
Set-Content -Path ok.json -Value (@{code=$r.demo_otp} | ConvertTo-Json -Compress) -Encoding ascii

5.3 Xác thực OTP SAI -> 400, tiền không đổi

curl.exe -i -X POST "http://127.0.0.1:8000/api/transfers/$($r.transaction_id)/confirm" -H "Content-Type: application/json" -d "@wrong.json"

5.4 Xác thực OTP ĐÚNG -> 200 SUCCESS

curl.exe -i -X POST "http://127.0.0.1:8000/api/transfers/$($r.transaction_id)/confirm" -H "Content-Type: application/json" -d "@ok.json"

Mong đợi: sender_balance_after 850000, receiver_balance_after 600000.

5.5 Dùng lại OTP đã dùng -> 409

curl.exe -i -X POST "http://127.0.0.1:8000/api/transfers/$($r.transaction_id)/confirm" -H "Content-Type: application/json" -d "@ok.json"

5.6 Số tiền vượt số dư -> 400

Set-Content -Path big.json -Value '{"sender_wallet_id":1,"receiver_wallet_id":2,"amount":999999999}' -Encoding ascii
curl.exe -i -X POST http://127.0.0.1:8000/api/transfers -H "Content-Type: application/json" -d "@big.json"

5.7 Kiểm tra kết quả: số dư và Ledger (có 2 dòng DEBIT + CREDIT mới)

Invoke-RestMethod http://127.0.0.1:8000/api/wallets
Invoke-RestMethod http://127.0.0.1:8000/api/ledger

Sau đó bấm "Tai lai du lieu" trên trang admin để thấy thay đổi.


==================================================
BƯỚC 6 - CHẠY TEST TỰ ĐỘNG (Terminal 2)
==================================================

python tests/test_api.py

Kết quả đúng: "Ket qua: 25 dat, 0 loi"
Bao gồm: routing, validate input, luồng thành công, OTP sai / dùng lại / hết hạn,
tổng tiền hệ thống không đổi.


==================================================
BƯỚC 7 - DỌN DẸP VÀ RESET ĐỂ DEMO LẠI TỪ ĐẦU
==================================================

Remove-Item wrong.json, ok.json, big.json -ErrorAction SilentlyContinue

Ctrl+C ở Terminal 1 để dừng server, rồi:

python database/init_db.py
python backend/server.py


==================================================
GHI CHÚ
==================================================

- Dùng curl.exe (không phải curl) trong PowerShell. Không truyền JSON trực tiếp
  bằng -d "{...}" vì PowerShell 5.1 làm mất dấu nháy kép, server sẽ trả
  400 "Body khong phai JSON hop le". Luôn dùng file JSON như ở Bước 5.2.
- Invoke-RestMethod ném lỗi khi gặp 4xx/5xx và không in nội dung lỗi,
  nên các trường hợp lỗi dùng curl.exe -i để thấy status code.
- test_api.py sửa trực tiếp DB (giả lập OTP hết hạn), nên phải chạy cùng máy
  với server. Muốn demo lại thì reset theo Bước 7.
- Thời gian trong DB lưu theo giờ UTC (chậm hơn giờ Việt Nam 7 tiếng).

TRÌNH TỰ GỢI Ý KHI DEMO CHO THẦY
1. Mở trang admin (Bước 2).
2. Chạy luồng chuyển tiền (Bước 5), cho thấy tiền thay đổi trên trang admin.
3. Chạy python tests/test_api.py (Bước 6) để cho thấy các trường hợp lỗi đều được xử lý.
4. Nếu Thầy hỏi request đi vào server thế nào: mở server.py, chỉ vào do_POST,
   dispatch, match (routing) và read_json_body (parse body).
